02 / Le code proposé

Une règle tient dans cette condition.

La remise dépend du code appliqué et du sous-total. Les tests doivent distinguer les comportements aux bornes.

Basket.cs / DiscountAmount()C#
public decimal DiscountAmount()
{
    if (PromoCode != PromotionCodes.Promo10
        || Subtotal() < PromotionCodes.MinimumSubtotal)
    {
        return 0m;
    }

    var discount = RoundMoney(
        Subtotal() * PromotionCodes.DiscountRate);
    return Math.Min(discount,
        PromotionCodes.MaximumDiscount);
}

05 / L’assertion qui compte

Un test existant atteint exactement 50 €.

BasketPromotion.cs / extrait d’un [Fact]xUnit v3
var basket = new Basket("buyer");
basket.AddItem(1, 25m);
basket.ApplyPromoCode("PROMO10");

Assert.Equal(0m, basket.DiscountAmount());

basket.AddItem(1, 25m);

Assert.Equal(PromotionCodes.Promo10, basket.PromoCode);
Assert.Equal(50m, basket.Subtotal());
Assert.Equal(5m, basket.DiscountAmount());
Assert.Equal(45m, basket.Total());
Détection attendue

Le mutant renverrait 0 € de remise.

Cette assertion exige 5 €. Elle devrait échouer lorsque le mutant est actif.

KeepsPromoCodeWithoutDiscountBelowMinimumAndRecalculatesAfterQuantityChange

À confirmer dans le rapport : statut Killed et test détecteur.
